# computer-vision
computer vision course

## Prerequisites

- Python 3.11+
- Git
- Webcam

## Setup

Clone the repository:

```bash
git clone https://github.com/theGame/computer-vision.git
cd computer-vision
```

### 3. Create a virtual environment
```bash
python -m venv myenv
```

Activate it:

Windows:
```bash
myenv\Scripts\activate
```
```bash
macOS/Linux:
source myenv/bin/activate
```
### 4. Install dependencies
```bash
pip install -r requirements.txt
```

I'd also mention that `requirements.txt` contains the project's Python dependencies.

### 5. Run the application

```bash
python color_capture.py
```

### 6. How to stop it

Since your application uses `q`:

```markdown
Press `q` to stop the application.
```
